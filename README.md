# BTermDock

BTermDock — терминал GTK для Linux с вкладками, панелью SSH-профилей и настраиваемым фоном.

## Установка

Распакуйте архив, откройте каталог `BTermDock` и запустите установщик от своего пользователя.

```sh
sh ./install.sh
```

Установщик проверяет зависимости и при необходимости предлагает установить их через системный менеджер пакетов. Для этого он вызывает `sudo` или `doas`. Приложение устанавливается в `~/.local/bin/bterm-dock`, а ярлык появляется в меню приложений. Для обновления распакуйте новую версию и повторите ту же команду.

| Дистрибутив | Менеджер пакетов |
| --- | --- |
| Arch Linux, Manjaro, EndeavourOS и совместимые | `pacman` |
| Debian, Ubuntu, Linux Mint и совместимые | `apt-get` |
| Fedora и совместимые | `dnf` |
| openSUSE | `zypper` |
| Alpine Linux | `apk` |
| Void Linux | `xbps-install` |

На Arch установщик использует `pacman -S --needed`. Если базы пакетов устарели и скачивание завершилось ошибкой, обновите систему обычной командой `sudo pacman -Syu` и повторите установку. На Alpine пакет VTE находится в репозитории `community`.

Для систем с другим менеджером пакетов или неизменяемым системным разделом установите зависимости средствами своего дистрибутива. Нужны Python 3.9 или новее с PyGObject и Pycairo, GTK 3, VTE с typelib `Vte-2.91`, Linux-PAM и клиент OpenSSH. Приложению нужна графическая сессия Wayland или X11. После установки зависимостей запустите скрипт с `--skip-deps`.

```sh
sh ./install.sh --skip-deps
```

Если системный Python находится по нестандартному пути, передайте его через `BTERM_PYTHON`, например `env BTERM_PYTHON=/path/to/python3 sh ./install.sh --skip-deps`.

## Запуск

Откройте BTermDock в меню приложений или запустите его из командной строки.

```sh
~/.local/bin/bterm-dock
```

В ярлыке или настройках горячих клавиш укажите полный путь к `~/.local/bin/bterm-dock`. С установленными зависимостями приложение также можно запустить прямо из каталога проекта.

```sh
python3 bterm-dock.py
```

Локальные вкладки используют оболочку из `$SHELL`. Если она недоступна, BTermDock пробует оболочку учётной записи, затем `/bin/sh`. Для запуска Bash, Zsh, Fish и других оболочек используется псевдотерминал, чтобы оболочка сама определила интерактивный режим.

При следующем запуске BTermDock восстанавливает порядок вкладок, активную вкладку и рабочие каталоги. Чтобы продолжить работу в восстановленной SSH-вкладке, нажмите «Подключиться» внизу терминала и подтвердите действие паролем Linux. Состояние вкладок хранится рядом с настройками в `session.json`.

В SSH-панели адреса скрыты при открытии окна. Кнопка с глазом открывает их после проверки пароля текущей учётной записи Linux через PAM. Повторное нажатие снова скрывает адреса. Профили остаются доступны для подключения в обоих режимах. При удалении профиля приложение запрашивает пароль Linux в диалоге с названием профиля.

При первом запуске без локальных настроек список SSH пуст. В меню **☰** в верхней части SSH-панели доступны экспорт в JSON и импорт из JSON. Резервная копия содержит адреса, параметры, порядок профилей и доступные значки. Для SSH-ключей сохраняются пути к файлам. При импорте можно добавить профили к текущим или заменить список целиком.

В «Настройках» есть светлая, тёмная, OLED и своя тема. Во вкладке «Своя тема» можно выбрать фон интерфейса, цвет текста и акцент. Цвет SSH-панели задаётся отдельно для каждой темы. Тема меняет окна, меню и вкладки. Если установлен GNOME Terminal, BTermDock использует его профиль для начального оформления рабочей области. Шрифт, история прокрутки и форма курсора настраиваются отдельно. Изменения сохраняются по кнопке «Применить».

В редакторе «Фон» изображение выбирается в галерее с миниатюрами, поиском по папке и большим предпросмотром. Изображение можно перетащить в превью терминала, изменить масштаб, приглушение и цвет свободной области. Кнопка «По центру» сбрасывает положение. Изменения видны сразу и сохраняются по кнопке «Применить».

## Где менять код

| Файл | Назначение |
| --- | --- |
| `bterm_dock/app.py` | Запуск приложения и обработка `--new-window` и `--new-tab` |
| `bterm_dock/window.py` | Главное окно, разделитель и сочетания клавиш |
| `bterm_dock/terminal.py` | Вкладки, сеансы VTE и настройки шрифта и палитры |
| `bterm_dock/tabs.py` | Полоса вкладок и их перестановка |
| `bterm_dock/sidebar.py` | SSH-панель, поиск, редактор профилей и перетаскивание |
| `bterm_dock/profile_drag.py` | Анимация перестановки SSH-профилей |
| `bterm_dock/ssh.py` | Проверка SSH-адресов и построение команды OpenSSH |
| `bterm_dock/auth.py` | Диалог пароля и проверка через Linux-PAM |
| `bterm_dock/profile_backup.py` | Экспорт и импорт списка SSH-профилей |
| `bterm_dock/background.py` | Отрисовка, масштаб, затемнение и предпросмотр фона |
| `bterm_dock/images.py` | Выбор изображений и значки профилей |
| `bterm_dock/gallery.py` | Галерея файлов и предпросмотр изображений |
| `bterm_dock/preferences.py` | Окно настроек BTermDock |
| `bterm_dock/appearance.py`, `bterm_dock/style.css` | Темы и стили GTK |
| `bterm_dock/settings.py` | Чтение и запись настроек |
| `bterm_dock/_gtk.py`, `bterm_dock/widgets.py` | Подключение GTK и общие элементы интерфейса |

Пользовательские настройки хранятся в `~/.config/zsh-dock/config.json` или в каталоге `$XDG_CONFIG_HOME/zsh-dock`, если эта переменная задана. После правок Python или CSS запустите приложение заново.
